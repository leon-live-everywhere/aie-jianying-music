# Leon 的私人音乐库（剪映常用 100 首）

**私人 repo，只给自己剪片用，不要公开、不要放进会分享出去的技能。**
歌是从 Leon Mac 上剪映的音乐缓存（`~/Movies/JianyingPro/User Data/Cache/music`）挑出来的，授权以剪映 / 原曲为准，公开发布前自己确认。

## 怎么挑出来的（2026-10-28）
- 剪映缓存没有歌名，档名只是一串代码。
- 排序：在剪映下载记录里出现 2 次的排前面（标「常用」，27 首），其余 73 首是最近打开过的（标「最近」）。
- 只收 30 秒以上的（短的是音效，不算歌）。

## 档名怎么读
`001_舒缓_纯音乐_快_轻松_185bpm_1m36s.mp3` = 编号 · 主分类 · 纯音乐/有人声 · 节奏（快 ≥118 / 中 92–117 / 慢 <92 bpm）· 感觉（有冲劲 / 明亮 / 轻松 / 安静，用音量和明亮度粗估）· bpm · 长度。
「常用 / 最近」现在放在 `index.json` 的 `source`。bpm 和感觉是程式估的，可能偏（例如快歌被算成两倍 bpm），挑的时候以耳朵为准。

## 分类（照剪映音乐库的分类名，2026-10-28）

每首歌有一个**主分类**（档名第二格）+ 最多 2 个副分类，外加「纯音乐 / 有人声」。分类是 AI 听歌估的（AudioSet 声音模型 + bpm），**不是剪映官方标签**；剪映 App 那天没办法点进去看分类，所以用的是剪映常见的分类名。听起来不对就直接改 `index.json` 的 `category` / `categories`。

## 给 Claude（aie-chat 剪片 ⑥ 音乐那一关）
1. `git clone` 这个 repo（或只抓 `index.json` + 要的那几首）。
2. 照片子的调性从 `index.json` 挑 3 首**不同分类**的（干货/有冲劲 → 动感、电子、卡点；讲故事 → 舒缓；轻松生活 → 轻快、VLOG；Leon 喜欢的 Funk → R&B / 爵士），口播片优先 `vocal=false`，再优先 `used_twice=true`。
3. 用 `music.py apply <音效版> --file songs/xxx.mp3 --level 0` 出预览，让 Leon 挑。
